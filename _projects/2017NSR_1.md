This project addresses the challenges of network traffic classification in control systems by proposing an automated method for identifying application-level traffic. Control systems, also known as SCADA (Supervisory Control And Data Acquisition) or Industrial Control Systems (ICS), are critical management systems used in national industrial infrastructures such as water and sewage, power plants, and airports. An attack on these systems can cause serious problems and significant damage, making research into intrusion detection technology for them very important. However, existing intrusion detection systems are difficult to use in control systems, which have different characteristics from general networks.

The approach of this project is to understand the unique structure and protocols of SCADA systems. This involves analyzing network traffic to identify its characteristics and regular patterns, creating a baseline 'profile', and then detecting anomalies that deviate from this profiling. To overcome the limitations of existing traffic classification systems, this project introduced an automated application traffic signature detection method based on Latent Dirichlet Allocation (LDA). LDA is a probabilistic text modeling technique used to extract latent semantic information from text. The core concept of this method is to treat a traffic flow as a document and its payload data as words. The LDA model analyzes the payload data to discover latent 'topics', which are collections of signature strings with associated probabilities.

The system architecture consists of three main components: a traffic classifier module, an update module, and data processing and output components. The process begins with primary classification using a payload-based classifier like [crl_pay](https://dl.acm.org/doi/abs/10.1145/1544012.1544023)[^1]. This step classifies known application types and separates unclassified flows. The unclassified flows are then passed to the update module, where LDA analyzes the payload data. The LDA model uses a sliding window approach to extract words from the payload and creates a frequency-based dictionary. The LDA algorithm then generates topics and assigns them to each flow. This multi-round classification continues until all flows receive topic assignments or a predefined number of rounds is reached. Through this process, new application signatures are automatically extracted and added to the signature database, allowing the system to adapt to new and evolving applications.

Specifically, this project applied this method to a control system network. The project analyzed water resource control system traffic data (approx. 44 GB, 3 hours). The results showed that existing tools like [crl_pay](https://dl.acm.org/doi/abs/10.1145/1544012.1544023)[^1] and [nDPI](https://github.com/ntop/nDPI) struggled to classify the specialized traffic. [crl_pay](https://dl.acm.org/doi/abs/10.1145/1544012.1544023)[^1] classified less than 10% of the total flows, leaving 90.1% as "Unclassified". Similarly, [nDPI](https://github.com/ntop/nDPI) classified approximately 87% of the total packets as "Unknown". The project then applied the LDA-based classification method to the "Unclassified' traffic, which accounted for approximately 42 GB of data. This approach successfully classified 122,611 flows, which represents 83.54% of the total traffic and 96.3% of its total size. This demonstrates that the proposed LDA-based method can effectively analyze control system traffic that was difficult to detect with existing tools, proving its effectiveness in specialized environments like SCADA systems.

[^1]: Kim, Hyunchul, et al. ["Internet traffic classification demystified: myths, caveats, and the best practices."](https://dl.acm.org/doi/abs/10.1145/1544012.1544023) Proceedings of the 2008 ACM CoNEXT conference. 2008.

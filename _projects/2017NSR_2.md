This project researched methods for collecting network traffic from anonymity networks. This study focused on directly collecting and investigating traffic from the Tor network, a widely used anonymity system. The primary goal was to analyze this traffic to understand the types of packets and the network's underlying structure.

The traffic collection method concentrated on setting up and operating a Tor Exit Node. The Exit Node is the final relay in a Tor circuit, which transmits the client's request to the destination server. At this point, the traffic is unencrypted, which allows for the collection and analysis of the full packet payload.

The research also included a comparative analysis of traffic data collected from a client's perspective. By using the Tor Browser, the researchers were able to track the circuit path (Entry, Middle, and Exit relays) and gather location data for the relays. This client-side data confirmed that Tor circuits are typically composed of relays spanning different countries and that new circuits are often built for each new connection, thereby ensuring user anonymity.

In conclusion, this research successfully established an effective method for collecting Tor network traffic data by operating an Exit Node. The collected data provided valuable insights into the network's structure and traffic patterns.

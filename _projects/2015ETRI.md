Our project addresses the challenges of network traffic classification by proposing an automated method for identifying application-level traffic. Traditional traffic classification relied on well-known transport layer port numbers. However, this approach has become less reliable due to the increasing number of applications using dynamically assigned or random ports to conceal their identity. An alternative approach, traffic content analysis, involves deep inspection of packet payloads. While highly accurate, this method requires significant manual effort for signature generation and is vulnerable to changes in application protocols over time.

To overcome these limitations, our approach introduces an automated application traffic signature detection method based on Latent Dirichlet Allocation (LDA). LDA is a probabilistic text modeling technique that extracts latent semantic information from text. The core concept treats a traffic flow as a document and its payload data as words. The LDA model analyzes the payload data to discover latent topics, which represent sets of signature strings related to specific applications.

The system architecture consists of three main components: a traffic classification module, an update module, and a data input/output module. The process begins with primary classification using a payload-based classifier. This step classifies known application types and separates unclassified flows. The unclassified flows are then processed by the update module, where LDA analyzes the payload data. The LDA model uses a sliding window approach to extract words from the payload and creates a frequency-based dictionary. The LDA algorithm then generates topics and assigns them to each flow. This multi-round classification continues until all flows receive topic assignments or a predefined number of rounds is reached. This process enables automatic extraction of new application signatures and their addition to the signature database, allowing the system to adapt to new and evolving applications.
